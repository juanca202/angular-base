## 🔴 Prioridad alta

### ADR-001 — Arquitectura híbrida por capas (dependencias, config y estructura)

**Fuente:** docs/adr/ADR-001-hybrid-layered-feature-architecture.md · docs/standards/architecture.md
**Regla auditada:** Capas Core/Shared/Cross/Features, dirección de dependencias, path aliases `@/core|@/shared|@/cross|@/features`, y fitness functions con dependency-cruiser + regla ESLint `project-rules/require-layer-path-alias`.
**Estado:** ❌ Incumplido

**Evidencias:**
- ✔ Existen `scripts/arch/verify.mjs` y `scripts/arch/checks/architecture.mjs` (CR-002, CR-004).
- ✔ Angular 22 está en `package.json` (stack alineado con el ADR).
- ✖ No existen `src/app/core/`, `src/app/shared/`, `src/app/cross/`, `src/app/features/` (CR-001 layer-organization).
- ✖ No hay `paths` / aliases en `tsconfig.json` ni `tsconfig.app.json`.
- ✖ `dependency-cruiser` no está en `package.json` / lockfile; no existe `.dependency-cruiser.js`.
- ✖ `npx depcruise` resuelve el paquete placeholder `depcruise@1.0.0` (no el real `dependency-cruiser`) y no valida nada.
- ✖ No hay ESLint ni la regla custom `tools/eslint-rules/require-layer-path-alias.js`.
- ✖ No hay script `arch` en `package.json` (documentado en `scripts/arch/README.md`).
- ✖ `node scripts/arch/verify.mjs` reportó PASS en CR-002/CR-004 — **falso positivo** (herramientas ausentes / exit 0).

**Incumplimientos:**
- `src/app/` — faltan carpetas de capa `core/`, `shared/`, `cross/`, `features/`
- `tsconfig.json` / `tsconfig.app.json` — sin `compilerOptions.paths` para `@/core`, `@/shared`, `@/cross`, `@/features`
- `package.json` — falta `dependency-cruiser`, `eslint`, tooling TypeScript-ESLint; falta script `"arch"`
- `.dependency-cruiser.js` — archivo ausente
- `tools/eslint-rules/require-layer-path-alias.js` — archivo ausente
- `eslint.config.*` — configuración ESLint ausente

**Acción sugerida:** Instalar y configurar las dependencias de verificación y la estructura mínima de capas/aliases (ver Fase 3.5 / pregunta al usuario). Corregir los checks para fallar si la herramienta no está instalada localmente.
