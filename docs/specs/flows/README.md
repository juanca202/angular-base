# Flujos de Usuario

Este directorio contiene la documentación de flujos de usuario y procesos de la aplicación.

## Propósito

Los documentos en este directorio describen:

- Flujos de interacción del usuario
- Procesos de negocio
- Secuencias de pasos para completar tareas
- Diagramas de flujo y casos de uso

## Formato

Cada flujo debe documentarse de manera clara y secuencial, incluyendo:

- Descripción del flujo
- Pasos detallados
- Condiciones y validaciones
- Casos alternativos o de error
- Diagramas cuando sea apropiado
