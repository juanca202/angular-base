# Glosario

Este directorio contiene definiciones de términos técnicos y de dominio utilizados en el proyecto.

## Propósito

El glosario ayuda a:

- Establecer un vocabulario común para el equipo
- Clarificar términos técnicos y de dominio
- Facilitar el onboarding de nuevos desarrolladores
- Mantener consistencia en la documentación

## Formato

Cada término debe incluir:

- **Término**: El nombre del concepto
- **Definición**: Descripción clara y concisa
- **Contexto**: Dónde y cómo se usa en el proyecto
- **Referencias**: Enlaces a documentación relacionada cuando aplique

## Agregar Nuevos Términos

Al agregar un nuevo término al glosario:

1. Crea o actualiza el archivo correspondiente
2. Sigue el formato establecido
3. Incluye ejemplos cuando sea apropiado
4. Referencia el término en la documentación relevante
